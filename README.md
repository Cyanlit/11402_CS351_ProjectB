# CSV Mini Database and Query Engine Development

## Project Overview

This project aims to develop a CSV Mini Database and Query Engine. The goal is to create a lightweight database system that can efficiently handle CSV files, allowing users to perform various queries and operations on the data stored within these files. The system will support basic CRUD (Create, Read, Update, Delete) operations, as well as more complex querying capabilities, enabling users to extract meaningful insights from their data.

## Features
- **CSV File Handling**: Load, parse, and manage CSV files seamlessly.
- **Query Engine**: Execute queries to filter, sort, and manipulate data.
- **User-Friendly Interface**: Provide a simple interface for users to interact with the database.
- **Performance Optimization**: Ensure efficient data processing and retrieval.

## Technologies Used
- Programming Language: Python
- Libraries: Pandas for data manipulation, SQLite for database management.

## Installation
1. Clone the repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Run the application using `python main.py`.

## Usage
- Load a CSV file using the command `load <filename>`.
- Execute queries using the command `query <your_query>`.
